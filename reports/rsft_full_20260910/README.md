# 第一轮正式RSFT

## 本轮设定

从SFT第2000步best_model开始，原6725道训练题全部参与，每题生成4条候选。
调用用户core.py筛选答案正确、格式合格、未截断的回答，再每题随机保留最多2条；不足2条不补齐。
不做文本去重，所以两个候选文本相同仍可能同时保留。两个样本的题与一个样本的题仍存在2:1权重差异。

每64题生成一批，用vLLM BF16推理，65%显存预算；各批原子保存，重启时跳过完整批。
本次采样后端与小试验Transformers不同，记录为本轮配置差异。
训练复用SFT组件，FP32参数和AdamW状态、BF16计算、梯度检查点，micro-batch=2、有效batch=8、
固定学习率5e-6、1个epoch。每200步及训练结束验证并保存模型和优化器断点。
验证固定200题，按答案正确率优先、loss次优挑选训练阶段最佳模型；完整测试1319题只在训练后使用。
前次SFT完整测试已经保存，可作为参考对照；本轮额外重新评估相同200题的SFT验证基线。

## 启动检查

4项核心检查通过，Python语法检查通过。vLLM接口检查：8题生成32候选，按新规则选出13条，
采样约5.95秒（含首次内核编译，不作为正式吞吐）。该检查产物单独保存，不混入正式训练数据。
