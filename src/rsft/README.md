# src/rsft

练习：生成候选回答、记录评分、筛选正确样本、复用 SFT。输入 SFT checkpoint，输出 RSFT checkpoint。

## 当前文件

- `core.py`：你编写的候选筛选与统计。本次仅修正题目覆盖率为“覆盖题数 / 总题数”。
- `check_core.py`：检查八种布尔组合、空输入、题目去重、保留顺序和不修改原数据。
- `run_trial.py` / `run_trial.sh`：服务器配套，调用你的核心函数，复用已有SFT组件。
- `trial_config.json`：本次小规模试验参数与路径。

## 本次试验

从原6725道训练题中固定随机选择100题，每题生成4个回答；使用原评分器填写候选字段，
再调用`select_correct_samples`和`summarize_candidates`。生成回答不重新套think/answer标签。
保留全部合格候选，不去重；因此同一道题可能贡献多条训练样本，这是当前练习的规则。

以SFT的best_model为起点，对筛选数据训练1轮；学习率5e-6、micro-batch=2、有效batch=8。
在相同20道验证题上做训练前后对比，保存并实际重载模型；不使用test采样或训练。
生成与训练分别运行以释放模型显存。此试验没有中途训练续跑功能，失败时保留诊断数据再处理。

运行：`bash run_trial.sh`。默认输出目录不可已存在，以免覆盖结果。
服务器代码位于`/root/workspace/test/src/RSFT_trial_20260910`，日志在
`/root/autodl-tmp/rsft-trial-20260910.log`，产物在`/root/autodl-tmp/rsft-trial-20260910`。

## 实验报告

该阶段结果：验证正确率从70%提升到76%，但是完整测试正确率从66.57%下降到65.2%。
loss 从 0.4496降到0.4256，但正确率没有提升
初步判断：
1.筛选模型自身回答的答案不够优秀，评分仅包含了答案正确，格式正确，未被判错三个方面，没有细致到具体的推理过程，筛选出来的自身答案价值不够
2.模型学习自身的重复逻辑，同一题目筛选出来的答案大多雷同，哪怕已经使用每道题目只选用最多两个回答的方式，但依旧存在思维僵化，即只学到了简单的题目，学不会难题的可能
3.验证集选择的题目太过简单，与测试集上的题目未必一一对应
