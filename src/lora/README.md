# src/lora

练习：手写低秩线性模块、冻结基座、注入 FFN、保存 adapter、跨领域评估。

- `core.py`：学习核心算法。
- `checks/`：CPU 核心和运行接口检查。
- `runtime/`：物理解题数据划分、梯度累积训练、断点恢复、adapter 加载、测试生成和合并导出。
